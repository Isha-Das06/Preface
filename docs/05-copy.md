# Product Copy

Voice: plain, specific, confident. Short sentences. No exclamation marks outside the completion screen. Never "seamless," "effortless," "supercharge," "powerful," "revolutionize," or "AI-powered." Say what happens.

Test for every line: *would a busy agency owner read this and immediately know what it means?*

## Section 8 — objections
> **Do I need to move my tools over?**

>
> **Is a typed signature actually valid?**

>
> **What happens when someone doesn't finish?**
> We remind them at two days and five days, then stop. You can send one manually any time. Nobody gets nagged forever.
