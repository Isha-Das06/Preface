## The five rules

1. **Simple beats powerful.** Feature vs. less friction → less friction, every time.
2. **The client never makes an account.** Structural advantage; don't trade it away.
3. **A brand-new signup must reach a sendable link without connecting Stripe, writing an agreement, or uploading a logo.** Violating this kills activation.
4. **Steps are snapshotted onto an onboarding at send time.** Editing a workflow never mutates one in flight.
5. **Build order is fixed:** design system → frontend with mock data → **review** → backend. Never reversed.
